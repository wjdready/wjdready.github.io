Windows 新安装时需要的操作

基于新安装的

  1. User 文件夹移动到D盘

  2. 显示扩展名和隐藏文件

  3. 添加到环境变量PATH

  4. VSCode

    然后重装系统后再到官网安装最新版本即可, 也可在 D:\Softwave\Devs 找之前备份版本

  5. 安装最新 pwsh 并设置终端默认为 pwsh

  6. mise 配置

  7. 设置->系统->开启开发者选项 (flutter编译需要)

  2. 常用字体安装

  3. 360zip 关联

  4. 注册表

  1. mise 路径手动添加到系统 PATH

  2. 关闭 hyper-v (待验证: 之前关闭是因为 VMWare 冲突但是现在 VMWare 安装时有 WHP 选项，似乎就可以不关闭 hyper-v 了) Windows-V-v.bat
